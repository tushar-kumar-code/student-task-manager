# 📋 Student Task Manager

A professional Task Management web application built using Flask and SQLite.

## 🚀 Features

- User Login Authentication
- Session Management
- Add Task
- Edit Task
- Delete Task
- Mark Task as Completed / Pending
- Task Priority (High, Medium, Low)
- Due Date
- Dashboard Statistics
- Bootstrap 5 Responsive UI
- SQLite Database

---

## 🛠 Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Bootstrap 5
- Jinja2
- Git & GitHub
